# NomBlog Frontend

A blog application built with React, Vite and Tailwind CSS.

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

Clone the repository:

    git clone https://github.com/nomansikandarr/nomblog-frontend

Install dependencies:

    npm install

Start development server:

    npm run dev
